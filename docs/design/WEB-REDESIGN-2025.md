# GarageOS - Rediseño Web 2025

## Diseño Actualizado

### Sidebar Moderno (AuthenticatedLayout)

**Referencias:**
- Soft UI Dashboard Pro (Creative Tim)
- Material Dashboard PRO
- Tailwind Dashboard Templates

**Características:**
- Sidebar colapsable con iconos pequeños cuando se contrae
- Header con logo y nombre de la app
- Grupos de navegación: "Principal" y "Operación"
- Badges de notificación (ej: "new" para Planes)
- Transiciones suaves al pasar por hover
- Footer con dropdown de usuario
- Breadcrumb automático en header

**Mejoras implementadas:**
1. Gradientes en elementos clave (logo, avatar)
2. Sombras y efectos visuales modernos
3. Badge de notificaciones
4. Iconos más variados (Shield, Calendar, Users, Receipt, TrendingUp)
5. Separadores visuales entre secciones
6. Texto "Gestión inteligente" en lugar de "Gestión vehículos"

### GuestLayout Mejorado

**Referencias:**
- Login pages de templates premium
- Diseños con gradientes modernos

**Características:**
- Logo más grande con gradiente
- Card con backdrop-blur
- Footer con iconos de características
- Texto "Gestión inteligente de vehículos"

## Paleta de Colores

- **Primary**: Color principal (azul/negro según tema)
- **Primary/80**: Variación más oscura para gradientes
- **Card**: Fondo de tarjetas
- **Muted**: Fondo secundario
- **Border**: Bordes sutiles

## Tipografía

- Fuente principal: Figtree (Google Fonts)
- Pesos: 400, 500, 600, 700
